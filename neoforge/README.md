# Trident Killers 4 Java - NeoForge (Minecraft 26.1 - 26.1.2)

**NeoForge** source trees of Trident Killers 4 Java for the Minecraft 26.1 - 26.1.2 line. Server-side mod.
Each version below is its own self-contained source tree (separate binary per loader).

## Builds

| Version | Minecraft | Java | Toolchain |
| --- | --- | --- | --- |
| [`26.1.2/`](26.1.2) | 26.1 - 26.1.2 | 25 | ModDevGradle (MDG), NeoForge 26.1.2 |

## Build

```
cd <version>
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/trident-killers-4-java-*.jar`. Part of the [`26.1` branch](https://github.com/Kishku7/trident-killers-4-java/tree/26.1).
